# AIにリサーチ・コンサルをさせる決まり

調査・相談・案出しをAIに頼むとき（`/kickoff`・`/consult`・調査役・反対役）に読む。

1. **選択肢は3つ**（「やらない」を含めてよい）。推奨1つと理由、各案のリスクを必ず付ける。「場合による」で終えない。決めきれないときは、決めるのに要る情報と、それが無いままの暫定推奨を書く
2. **事実・推測・意見を分ける**。行頭に【事実】【推測】【意見】を付け、事実には出典（URL・`ファイル:行`・観察ログの日付）を付ける。出典の無い事実は【推測】と書く
3. **案を出した役と別の役が弱点だけを書く**（反対役）。反対役は改善案・褒め言葉を書かない。案を出した側は弱点ごとに「受ける／退ける（理由1行）」で答える
4. **平凡に寄るのを防ぐ**
   - お手本を名指しする（具体的な作品・製品名と、借りる点）
   - 制約を強くする（時間・操作数・字数などに上限を置く）
   - 好みの見本（`docs/plan/taste-samples.md`）を渡す
   - 観察ログ（`docs/plan/observation-log.md`）を渡す
   - ありがちな案を先に1つ書き出し、それと違う案を出す
5. **AIの調査は使い手の代わりにならない**。AIが出すのは仮説まで。確かめるのは段2の3人の観察。「使い手は〜と感じるはず」は【推測】と書く
6. **長さ**：1回の回答は目安1,500字。超えるときは結論を先に書き、詳細はファイルへ
