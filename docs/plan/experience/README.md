# 体験票（steam-kids）

雛形は `docs/templates/experience-sheet.md`（配布物。ここでは編集しない）。体験を新しく決める Issue（新レッスン・作り直し・新しい画面や操作・子どもが見る演出）は完全版、それ以外は短縮版を使う。1件1ファイルで `docs/plan/experience/<lessonId または Issue番号>.md` に置く。

## 書き方の規則
1. あるべき瞬間（3つまで）に形容詞（楽しい・分かりやすい）を書かない。見えるものと行動で書く
2. わるい例は1つ以上。うち1つは必ず、いちばん手間の少ない実装がやりそうなことを書く
3. 確かめ方の【人・実機】には感じ方（楽しさ・音・指の感触・子どもの反応）だけを振る。画面に見えるかどうかは【機械】か【一目チェック】に振る

## 面ごとの票（steam-kids の追記）
完全版では「最初の10秒」の後に置く。列は次の4つに固定し、語を変えない（レッスンJSON の欄 #726・`design-difficulty` と同じ語）。

| 面 | 役割 | 気づくこと | 素直にやると何が起きるか | K1〜K3 または候補数 |
|---|---|---|---|---|

- 役割：であう／つかう／ひねる／まぜる／ひらく
- 気づくこと：「〜すると〜になる」の形（`docs/plan/judgment-guide.md` 1章 問1）

実例：#727 本文 3-2（#723 をこの型で書き直したもの）。
