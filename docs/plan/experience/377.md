# 体験票：377（なおす を ice・key・switch の p3 で使う）

## 短縮版

- 目標：cmd-03 の「なおす」を、こおり・かぎ・スイッチの盤で使う
- あるべき瞬間：
  1. p3 を開くと命令列が最初から並んでいて、子どもがまず「じっこう」を押す
  2. ぶつかったチップ（光る）を見て、その1つを×で消す
  3. 消した列でゴールし、ロボットが喜ぶ
- わるい例：「ぜんぶ けす」で列を空にして一から並べ直す（クリアはできるが、列を読んでいない）。手間の少ない実装がやりそうなこと：初期列を「最短の列の1手を別の向きに替えたもの」にして、ギミックと関係のない誤りにする
- 確かめ方：【機械】validate・E2E `naosu-reuse`／【人・実機】p3 で子どもが×を使ったか、ぜんぶ けすを使ったか
