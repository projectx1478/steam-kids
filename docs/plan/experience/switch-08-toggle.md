# 体験票：みっつの スイッチ（switch-08-toggle）

設計の正本：#376（段1）・#815。盤の数値は `node tools/analyze-board.mjs switch-08-toggle <面>` で確認済み。

- 体験の目標：スイッチには「あける」「だす」「かえる」の3種があると、自分で踏んで試して分かり、次の面でも踏む前に壁の動きを考えている。
- あるべき瞬間（3つまで）：
  1. p1 でスイッチを踏み、壁が消えるのを見て、p2 では同じように踏んで壁が出るのを見て「ちがう動きがある」と分かる。
  2. p4・p6 で同じスイッチをもう一度踏み、壁が元に戻るのを見て、踏む回数を数えて道を決め直す。
  3. p8 でどちらのスイッチを踏んでもゴールに着き、友だちと違う道を選んだと言える。
- わるい例：
  - 最もやりそうな手抜き：全面が「踏めば開く」だけの同じ盤で、スイッチの種類が変わっても手が止まらず、押すだけでクリアできる。
  - 壁が出る面（p2・p5）で、踏む前に何も起きない合図がなく、なぜ詰まったか分からない。
  - p8 の道が実は1本しかなく、「選ぶ」感じがない。
- くらべる相手：既存の switch-01〜02（開くだけ）。3種を1本に並べ、同じ盤の中では1種だけにして、迷わず違いに気づけるようにする。
- 最初の10秒：intro「スイッチを ふむと どうなる？」の見本が動き、p1 で子どもが矢印を並べ始める。
- 天井：p6 で「ひとつ踏むと2つの壁が変わる」を、実行前に言葉にして道を決められる。
- 床：何も分からなくても、p1・p2 は最短6手で、何度でもやり直してクリアできる。
- 確かめ方：子ども1人に8面を見てもらい、(1) p1 の最初の操作まで10秒以内、(2) p4〜p8 のどれかで手が止まって考える、(3) クリア後に自分からもう一度か次を開ける、を横で見る（段5の3項目）。
- 人が決めること：Fire タブレット・iPad での実機の手触りと、「ひらく」面（p8）が子どもに選ぶ楽しさとして届くか。
