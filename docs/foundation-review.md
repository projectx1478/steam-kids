# 根幹見直しレビュー（2026-10-02）

参加者は4役。learner-novice と learner-gamer は静止画14枚を見た。foundation-edu と foundation-designer は資料とコードを読んだ。各役の原文は `review/principles/round1/`・`round2/` にある。前回レビューの原文は `review/principles/archive/2026-10-02-principles-review/` へ移した。

## 結論
- 根幹16項目の判定は、維持9、条件付きで維持4、見直し候補1、証拠不足2。三原則が崩れる証拠は、資料にも観察にも無かった。
- 見直し候補は「全レッスンが計画型で、直接操作型がゼロ」の1件だけ。2つの操作モデルという分類は残す。直接操作型のレッスンを1本足して比べる。入口のレッスンは置き換えない。
- **最も重要な1点**：レッスン1本の長さ、続ける動機、対象学年の3つは、実プレイのログが無いため判断できない。次の3つを集計することが、どの変更よりも先になる。
  - 1レッスンにかかる実際の時間
  - p1（最初のステージ）にかかる秒数
  - 翌日以降にまた遊びに来たか
- 8ステージ化はログが出るまで保留する。試す順は、最終ステージの手応え（前回案D）を先、ステージ数を後にする。

## 前提と限界
- 音は聞いていない。動きは見ていない。根拠は静止画14枚のみ。
- 実プレイのログは見ていない。実際の観察は、保護者のメモ（子ども1人分）だけ。
- 学習者役2人の「学べた／学べなかった」は役の想像で、実際の学習効果の証拠ではない。learner-novice は初見の目を保つため、context.md と difficulty.md を読んでいない。
- 今の記録イベント（step_enter・run・retry・undo・stage_clear・clear・abandon）でわかるのは、遊んだかどうかと、どこで詰まったかだけ。概念を理解したかどうかは、どの案でも測れない。

## 意見が割れたまま残った点（決めるのは人間）
1. **最初のレッスンを直接操作型にするか**
   - novice・gamer：最初はさわってすぐ動くものがいい。
   - edu・designer：入口は計画型のまま、直接操作型は別のレッスンで比べる（どちらも第1ラウンドから後退して一致）。
2. **短い回の反復か、1レッスンを長くするか**
   - edu：分散学習の知見（Cepeda ら）では、短い回を繰り返す方が定着に有利。
   - designer：その知見は同じ内容の復習の保持が対象で、1レッスン内で難度を上げていく8ステージ化の反証にはならない（要確認）。
   - gamer：「まずログ」は待たされる感じがする。最後を難しくする方を先に。
3. **概念を言葉にする機能（読み上げ、クリア後のロボットの一言）**
   - novice・gamer：短く、さわった後なら欲しい。
   - edu：子どもに言語化を求める機能は足さない（証拠不足）。先に、新しいギミックの初回を文なしで通せるかを確かめる。
   - designer：文は足さず、シーソー1本で、保護者が「クリア後に子どもが自分の言葉で説明できるか」を観察する。
4. **集める要素（ロボットの服・飾り）**
   - gamer：集める絵があると明日もやりたい。ただし、終わりが見えない、すぐ次が出る、ランダムなごほうび、「あと1個」が続く、だとやめられなくなる。
   - designer：取り逃しが無い、時間で増えない、数や比較を出さない、の条件付きなら許す。
   - edu：中毒を避ける趣旨と衝突しうるので反対。
5. **二択の予想**
   - novice：初心者は手を出しやすくなる。ただし、すぐ×が出るのは嫌。gamer：○×が出ないならあってもいい。
   - edu・designer：禁止を維持し、文言を明確化するだけにする。
