# 教材の執筆ルール

レッスンの文言を書く・生成するときに読む。

## 禁止事項

- **長文説明を書かない**。1画面の文章は20字以内
- **専門用語を先に出さない**。体験してから名前を付ける
- **規則を intro に書かない**。intro の文は目的か問い（例：`ゴールまで {進|すす}もう`・`こおりの うえで どうなる？`）。規則の文（「〜すると〜よ」）は summary にだけ置く（Issue #717）
- **新ギミック初出レッスンの1面目は、規則を見つける面にする**。`maxCommands` 以内で、そのギミックに触れずにクリアできる命令列が0本、かつ触れたことで失敗になる命令列が0本（壁にぶつかる・手数が足りないなど、ギミック以外が原因の失敗は数えない。Issue #717）
- **tutorial の文は操作の説明だけにする**。規則の文を置かない（Issue #717）
- **失敗表示を出さない**。未達成時の文言は「ためしなおす」のみ。
  否定語（「ちがう」「まちがい」「ざんねん」）を`text`に使わない（`tools/validate-lessons.mjs`で機械チェック）
  例外：sort-order（レシピの順番）は、順序制約ごとの短い事実の1行（`before[].why`）を失敗の結果表示で出してよい（`docs/learning-spec.md`の sort-order の項）。
- **正誤採点・点数・ランキングを出さない**
- 教科書の図版・記述に寄せない
- 子ども画面に外部リンクを置かない

## 使用できる文字

- ひらがな主体で書く
- 漢字を使う場合は必ずルビ記法 `{漢字|よみ}` で書く（例: `{右|みぎ}へ すすもう`）。
  地の文に生の漢字を書かない。漢字は文部科学省「学年別漢字配当表」（`js/kanji-grades.js`）に
  含まれるものだけを使う。よみレベル（端末内設定）が配当学年未満の場合はひらがな表示に
  自動で落ちる（`docs/lesson-schema.md`「ルビ記法」）
- カタカナは「ゴール」「マス」など日常語に限る
- 英数字は命令名に使わない（`up` ではなく「うえ」と表示する）
- 文節ごとに半角スペースを入れる分かち書きで書く（例: `おなじ {道|みち}を みじかく しよう`）。
  読点の代わりに区切りとして機能させ、ひらがな連続による誤読を防ぐ（Issue #97）

## 文言の持ち方

文言はレッスンデータ側の文字列として持ち、DOMテンプレートに直書きしない。
音声読み上げはMVP対象外だが、将来 Web Speech API から同じ文字列を読める構造を保つため。
