# 教材の執筆ルール

レッスンの文言を書く・生成するときに読む。

## 禁止事項

- **長文説明を書かない**。1画面の文章は20字以内
- **専門用語を先に出さない**。体験してから名前を付ける
- **失敗表示を出さない**。未達成時の文言は「もういちど」のみ。
  否定語（「ちがう」「まちがい」「ざんねん」）を`text`に使わない（`tools/validate-lessons.mjs`で機械チェック）
- **正誤採点・点数・ランキングを出さない**
- 教科書の図版・記述に寄せない
- 子ども画面に外部リンクを置かない

## 使用できる文字

- ひらがな主体で書く
- 漢字を使う場合は必ずルビ記法 `{漢字|よみ}` で書く（例: `{右|みぎ}へ すすもう`）。
  地の文に生の漢字を書かない。漢字は文部科学省「学年別漢字配当表」（`js/kanji-grades.js`）に
  含まれるものだけを使う。よみレベル（端末内設定）が配当学年未満の場合はひらがな表示に
  自動で落ちる（`docs/lesson-schema.md`「ルビ記法」）
- カタカナは「ゴール」「マス」など日常語に限る
- 英数字は命令名に使わない（`up` ではなく「うえ」と表示する）

## 文言の持ち方

文言はレッスンデータ側の文字列として持ち、DOMテンプレートに直書きしない。
音声読み上げはMVP対象外だが、将来 Web Speech API から同じ文字列を読める構造を保つため。
