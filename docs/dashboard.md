# ダッシュボード仕様

P2着手時に読む。保護者・教師向けの**読み取り専用**画面。子ども画面とは別URL。

## 表示内容

- レッスンごとの状態（未着手 / 途中 / クリア）
- ステップ別の滞在時間、やり直し回数、予想の正誤
- 離脱が発生した地点
- 直近7日の取り組み

## 詰まりアラート

次のいずれかに該当するステップを強調表示する。

- やり直し3回以上
- 滞在時間が同ステップ中央値の2倍以上
- 予想を2回連続で外している

この画面が観察メモの代替になる。**手入力のメモ機能は作らない。**

## 未決事項

ダッシュボードの認証方法は未決。家庭利用では不要だが、校内配布時に教師向けの保護をどうするか
を決める必要がある。
