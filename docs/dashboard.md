# ダッシュボード仕様

P2着手時に読む。保護者・教師向けの**読み取り専用**画面。子ども画面（`index.html`）とは
別URL（`/dashboard.html`）で実装する。**子ども画面からリンクは置かない**（URL直打ちのみ）。
**認証は付けない**（P2時点。校内配布の話が出た時点で決める。「未決事項」参照）。
データは同期せず、この端末の localStorage にあるものだけを表示する。

呼び名（`label`）の入力欄はこの画面に置く。localStorage のみに保存し、同期先へは送らない。

## 表示内容

- レッスンごとの状態（未着手 / 途中 / クリア）
- ステップ別の滞在時間、やり直し回数、予想の正誤
- 離脱が発生した地点
- 直近7日の取り組み

## 詰まりアラート

次のいずれかに該当するステップを強調表示する。判定は `js/analytics.js` の
`summarize(events, now)`（純粋関数）が行う。画面側は結果を描画するだけにする。

| 条件 | 判定 |
| --- | --- |
| やり直し3回以上 | 同一レッスン・同一ステップの `retry` 件数が3以上 |
| 滞在時間が同ステップ中央値の2倍以上 | 同一ステップの滞在時間サンプルが3件以上あるとき、最新の滞在時間が全サンプルの中央値の2.0倍以上 |
| 予想を2回連続で外している | 同一ステップの `predict` を時系列順に並べ、直近2件がともに不正解 |

- 滞在時間サンプルは `step_enter` を開始、直後の `step_leave` または `abandon`
  （同一ステップ）を終端として1件を作る。終端が無い滞在（クラッシュ等）は計上しない
- サンプル3件未満では滞在時間の判定を行わない（母数が少なく初回から誤検知するため）
- 予想の判定は「直近2件」のみを見る。過去に2連続で外した履歴が判定に残り続けないようにするため

## レッスン状態・離脱地点・直近7日

- **レッスン状態**: `step_enter` が無ければ未着手。あるが `clear` が無ければ途中。
  `clear` があればクリア
- **離脱地点**: `clear` が後続しない最後の `abandon` の `stepId`。クリア済みなら無し（`null`）
- **直近7日**: 表示時点（`now`）から遡って7日分を日別（UTC日付）に集計する。取り組みが
  無い日も0件として含む

この画面が観察メモの代替になる。**手入力のメモ機能は作らない。**
